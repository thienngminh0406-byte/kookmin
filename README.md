# 국민대 근처 자취방 리스트 — 완전 자동화 버전

**매일 아침 9시, 고방·카카오에서 최신 매물을 자동으로 긁어와 사이트에 반영**합니다.
사람이 엑셀을 손으로 고칠 수도 있고(수동 보정용), 그냥 놔둬도 매일 새로 갱신됩니다.

```
repo/
├── data/
│   └── listings.xlsx        ← 자동 수집 결과 (직접 고쳐도 되지만, 다음날 9시에 덮어써짐)
├── docs/
│   ├── index.html           ← 웹사이트 화면 (거의 수정할 일 없음)
│   └── data.json            ← listings.xlsx로부터 자동 생성됨 (직접 수정 X)
├── scripts/
│   ├── collect_data.py      ← 고방+카카오 API에서 매물을 새로 수집하는 스크립트
│   └── build_data.py        ← 엑셀 -> data.json 변환 스크립트
├── netlify.toml              ← Netlify 배포 설정 (docs 폴더를 배포)
└── .github/workflows/
    └── update-data.yml      ← 매일 자동 수집 + 수동 수정 시 반영, 둘 다 처리하는 GitHub Actions
```

## 1. 처음 한 번만 하는 설정

### 1) GitHub에 저장소 만들기
1. github.com에서 팀/조직 계정으로 새 저장소(Repository)를 만듭니다. (Public이어야 무료로 Pages를 쓸 수 있어요. 학교/팀 정보라 공개가 부담되면 GitHub 유료 플랜의 Private Pages를 알아보세요.)
2. 이 폴더(`repo/`) 안의 모든 파일과 폴더를 그 저장소에 업로드합니다.
   - GitHub 웹사이트에서 "Add file → Upload files"로 드래그 앤 드롭 해도 되고,
   - 터미널을 쓸 줄 아는 분이 있다면 아래처럼 해도 됩니다:
     ```
     cd repo
     git init
     git add .
     git commit -m "초기 업로드"
     git branch -M main
     git remote add origin https://github.com/<계정명>/<저장소명>.git
     git push -u origin main
     ```

### 2) Netlify에 연결해서 배포하기
1. netlify.com에서 로그인 후 **"Add new site" → "Import an existing project"**
2. GitHub 선택 → 방금 만든 저장소 선택
3. Build settings는 그냥 두셔도 됩니다 — 레포 안에 있는 `netlify.toml`이
   "docs 폴더를 배포하라"고 자동으로 알려줍니다. (Publish directory를 직접
   `docs`로 입력해도 동일합니다.)
4. Deploy 누르면 1분 이내로 실제 웹사이트 주소가 생깁니다.
   (`https://<임의이름>.netlify.app` 형태, Netlify 설정에서 원하는 이름으로 바꿀 수 있어요)
5. 이후로는 GitHub 저장소에 커밋이 올라올 때마다(=아래 4번 순서처럼 엑셀을
   업데이트할 때마다) Netlify가 자동으로 감지해서 재배포합니다. 따로 만질 것 없어요.

### 3) Actions 쓰기 권한 켜기 (중요!)
자동 업데이트가 작동하려면 GitHub Actions가 파일을 다시 커밋할 수 있어야 하고,
그래야 그 커밋을 Netlify가 감지해서 재배포합니다.
1. **Settings → Actions → General**로 이동
2. 아래쪽 "Workflow permissions"에서 **Read and write permissions** 선택 → Save

이 설정을 안 하면, 엑셀을 업데이트해도 자동 반영이 안 되고 Actions 탭에 빨간 X(실패)가 뜹니다.

### 4) 카카오 API 키를 Secret으로 등록하기 (완전 자동 수집을 위해 필수)
매일 아침 고방 + 카카오에서 새로 데이터를 긁어오려면 카카오 REST API 키가 필요합니다.
저장소 코드에 직접 적지 않고, GitHub의 "Secret" 기능으로 안전하게 등록합니다.

1. **Settings → Secrets and variables → Actions**로 이동
2. **New repository secret** 클릭
3. Name: `KAKAO_API_KEY` (정확히 이 이름이어야 합니다)
4. Value: 카카오 디벨로퍼스에서 발급받은 **REST API 키** 붙여넣기
5. **Add secret** 클릭

이렇게 등록하면 Actions 로그에도 키 값이 노출되지 않고, 저장소를 들여다봐도 아무도 키를
볼 수 없습니다. GitHub Actions가 실행될 때만 내부적으로 꺼내 쓰는 방식이에요.

## 2. 데이터는 이렇게 자동으로 갱신됩니다

**매일 한국시간 오전 9시**, GitHub Actions가 자동으로:
1. 고방 API에서 성북구·강북구 매물을 처음부터 다시 긁고
2. 각 매물 주변 편의점·카페·마트·병원·세탁소·우체국을 카카오 API로 다시 조회하고
3. `data/listings.xlsx`와 `docs/data.json`을 새로 만들어 커밋합니다
4. Netlify가 그 커밋을 감지해서 몇 초~1분 안에 사이트를 재배포합니다

사람이 할 일은 없습니다. 저장소의 **Actions** 탭에서 매일 실행 기록(성공/실패)을 확인할 수 있고,
지금 바로 한 번 돌려보고 싶으면 Actions 탭 → "매물 데이터 자동 업데이트" → **Run workflow**로
즉시 실행할 수 있습니다.

### 참고: 자동 수집이 못 찾는 매물이 있어요
지금 있는 46개 매물 중 일부(주로 성북구의 쉐어하우스·투룸 등)는 예전에 고방 **웹사이트를
직접 검색**해서 사람이 모은 거라, 고방 **API**로 도는 자동 수집 범위 밖에 있어요. 자동 수집은
API가 실제로 내려주는 유형(고시원·원룸텔·모텔 등 `scripts/collect_data.py`의
`HOUSE_TYPES_WIDE` 목록)만 갱신합니다. 나중에 브라우저 개발자도구로 쉐어하우스 등의
실제 API 유형 코드(`houseTypes` 값)를 새로 확인하게 되면, 그 스크립트의 목록에
추가해드릴 수 있어요.

## 3. 수동으로 엑셀을 고치고 싶을 때

자동 수집 결과가 마음에 안 들거나 특정 매물을 직접 손보고 싶다면:
1. `data/listings.xlsx`를 열어서 수정합니다.
   - 컬럼 이름은 절대 바꾸지 마세요 (아래 "엑셀 컬럼 설명" 참고).
2. 저장한 파일을 GitHub 저장소의 `data/listings.xlsx`에 그대로 덮어씁니다.
3. 이 커밋은 `docs/data.json`만 다시 만듭니다(고방·카카오를 다시 긁지 않아요) — 그래서
   방금 고친 내용이 그대로 반영됩니다.
4. 다만 **다음날 오전 9시 자동 수집이 돌면 이 수동 수정 내용은 덮어써집니다.** 특정 매물을
   계속 수동으로 유지하고 싶다면, `scripts/collect_data.py`가 그 매물을 건드리지 않도록
   저한테 다시 요청해서 코드를 조정할 수 있어요.

| 지하철역 / 지하철역거리m | 가장 가까운 역 이름과 거리(미터) | 비워도 됨 |
| 전화번호 | | 비워도 됨 |
| 주소 | 표시될 주소 | 필수 |

## 5. 화면(index.html)을 고치고 싶을 때

`docs/index.html`은 디자인/기능이 담긴 파일이라 평소엔 건드릴 필요가 없어요.
문구, 색깔, 새 기능 추가 등은 클로드에게 다시 요청하시고, 나온 결과물로
`docs/index.html`만 교체해서 커밋하시면 됩니다. (`docs/data.json`은 자동 생성 파일이라
직접 손대지 않아도 됩니다.)

## 6. 참고

- `docs/index.html`은 이제 `data.json`을 **인터넷으로 불러오는 방식**이라,더 이상
  파일을 더블클릭해서 여는 것만으로는 안 열려요 (브라우저 보안 정책 때문). 반드시
  Netlify 같은 웹 서버를 통해 열어야 합니다. 로컬에서 테스트하고 싶다면
  `docs` 폴더에서 `python3 -m http.server 8000` 실행 후 `localhost:8000` 접속하시면 됩니다.
- 매물 데이터는 gobang.kr, 카카오 지도 API 등에서 특정 시점에 수집한 정보이므로,
  실제 계약 전에는 항상 원본 링크에서 최신 정보를 확인하도록 사이트에 안내 문구가
  들어가 있습니다.
